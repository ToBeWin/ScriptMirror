# 镜词品牌资产

`scriptmirror-logo-v2.png` 是镜词 / ScriptMirror 的极简 App logo：以“镜框 + 提词光标 + 录制点”为核心，使用 Cyan `#16DDE0`、Recording Red `#FF4D4F` 和 Obsidian 深色体系。v1 保留在同目录，作为探索稿归档。

- RGBA 透明背景，1254×1254，适合 Flutter 品牌标记与 Android launcher。
- 小尺寸使用时保持 `BoxFit.contain`，不要裁掉四周的眼形轮廓。
- 品牌 UI 背景使用 `#0B0C0E`；不要额外叠加发光、渐变或文字。
- Android 启动页使用同一 Logo 的 256×256 安全区版本，并通过 adaptive icon 避免 Android 12+ 圆形遮罩裁切。
